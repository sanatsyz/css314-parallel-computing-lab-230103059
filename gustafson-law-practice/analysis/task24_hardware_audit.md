# Task 24 — Hardware audit and empirical discrepancy

Benchmark host: Apple M4, macOS 27.0.1, arm64; Python 3.14; `os.cpu_count()` reports 10 logical CPUs. This environment did not expose cache sizes, core topology, DRAM channel count, installed memory capacity, or NUMA topology through the collected portable metadata. Apple Silicon uses a unified memory architecture; memory-channel configuration was not independently verified, so no channel count is claimed. The machine is a laptop-class system whose power and thermal state can change during runs.

The Python multiprocessing benchmark assigned 100,000 deterministic arithmetic iterations per process and ran five trials at 1, 2, 4, 6, and 10 processes. Process creation and interpreter overhead dominate this short kernel; results therefore deteriorate at higher process counts and are not representative of a native numerical kernel. The fitted effective serial/overhead fraction is reported by `benchmarks/fit_summary.md`. Error bars in the plot are standard error from five measured speedup values. Thermal throttling and scheduling can contribute noise, but this dataset does not isolate them. NUMA boundaries are not applicable as a multi-socket configuration was not detected; on this host, memory is unified.
